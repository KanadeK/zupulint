# Roadmap

This roadmap describes candidate work, not a promise or compatibility guarantee. Privacy, deterministic behavior, and non-mutating source handling remain release gates.

## Near term

- Expand GEDCOM 7 event, citation, repository, and archival source coverage while preserving unknown extensions.
- Add more documented traditional/partial date forms without guessing unsupported calendar conversions.
- Improve column-mapping guidance and diagnostics for large institutional exports.
- Add opt-in duplicate thresholds only after stable calibration fixtures exist.

## Later

- Generate guided repair plans as separate reviewable artifacts; never rewrite an original file automatically.
- Model additional regional genealogy and succession conventions through explicit, versioned configuration.
- Add machine-readable rule profiles for archives, research workbooks, and publication checks.
- Improve accessibility and localization without creating a cloud dependency.

Feature requests should include a fictional fixture, expected behavior, false-positive risks, and privacy implications.
